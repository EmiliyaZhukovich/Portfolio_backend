# Веб-приложение для управления задачами

Это веб-приложение позволяет управлять списком задач: создавать, редактировать, удалять и отмечать задачи как выполненные. Приложение поддерживает как синхронную, так и асинхронную реализацию.

## Основные функции

- **Создание задач**: Добавление новых задач с указанием названия и описания.
- **Редактирование задач**: Изменение названия и описания существующих задач.
- **Удаление задач**: Удаление задач из списка.
- **Отметка задач как выполненных**: Переключение статуса задачи между "в ожидании" и "выполнено".
- **Хранение данных**: Все данные сохраняются в базе данных SQLite.

## Структура проекта

```
app_tasks/
├── __pycache__/          # Кэшированные файлы Python
├── instance/             # Папка для хранения локальных данных (например, базы данных)
├── migrations/           # Папка для миграций базы данных (Alembic)
├── static/               # Статические файлы (CSS, JS)
├── templates/            # HTML-шаблоны
├── alembic.ini           # Конфигурационный файл для Alembic
├── app_async.py          # Асинхронная версия приложения (Quart + SQLAlchemy)
├── models.py             # Модели базы данных (SQLAlchemy)
├── my_app.py             # Синхронная версия приложения (Flask + SQLAlchemy)
├── requirements.txt      # Зависимости проекта
└── tasks.db              # База данных SQLite
```

## Установка и запуск

### 1. Установка зависимостей

Убедитесь, что у вас установлен Python 3.8 или выше. Затем установите зависимости:

```bash
pip install -r requirements.txt
```

### 2. Запуск синхронной версии (Flask)

1. Перейдите в папку проекта:
   ```bash
   cd app_tasks
   ```

2. Запустите приложение:
   ```bash
   python my_app.py
   ```

3. Откройте браузер и перейдите по адресу:
   ```
   http://127.0.0.1:5000
   ```

### 3. Запуск асинхронной версии (Quart)

1. Перейдите в папку проекта:
   ```bash
   cd app_tasks
   ```

2. Запустите приложение:
   ```bash
   python app_async.py
   ```

3. Откройте браузер и перейдите по адресу:
   ```
   http://127.0.0.1:5000
   ```

### 4. Миграции базы данных (Alembic)

Если вы вносите изменения в модели базы данных, используйте Alembic для создания и применения миграций:

1. Создайте миграцию:
   ```bash
   alembic revision --autogenerate -m "Описание изменений"
   ```

2. Примените миграцию:
   ```bash
   alembic upgrade head
   ```

## Используемые технологии

- **Flask**: Микрофреймворк для создания веб-приложений на Python.
- **Quart**: Асинхронная версия Flask.
- **SQLAlchemy**: ORM для работы с базами данных.
- **Alembic**: Инструмент для управления миграциями базы данных.
- **SQLite**: Легковесная база данных для хранения задач.
